# ai-env-gen

Generate .env files by scanning your code for environment variables. Never miss a required config again.

## Install & Run

```bash
npx ai-env-gen
```

## What It Does

- Scans your codebase for `process.env.VAR` usage
- Detects Vite (`import.meta.env`), Deno, and destructured patterns
- Categorizes variables (Auth, Database, API, etc.)
- Generates `.env.example` with descriptions
- Uses AI to describe unknown variables

## Usage

```bash
# Scan current directory
npx ai-env-gen

# Scan specific directory
npx ai-env-gen -d ./src

# Custom output file
npx ai-env-gen -o .env.template

# Include placeholder values
npx ai-env-gen --include-values

# Merge with existing .env.example
npx ai-env-gen --merge

# Skip AI descriptions
npx ai-env-gen --no-ai
```

## Detected Patterns

- `process.env.VAR_NAME`
- `process.env['VAR_NAME']`
- `import.meta.env.VAR_NAME` (Vite)
- `Deno.env.get('VAR_NAME')`
- `const { VAR } = process.env`
- `env('VAR_NAME')` (Laravel-style)

## Options

```bash
Options:
  -d, --dir <path>       Directory to scan (default: ".")
  -o, --output <file>    Output file (default: ".env.example")
  -e, --extensions <ext> File extensions (default: "js,ts,jsx,tsx")
  --include-values       Add placeholder values
  --merge               Merge with existing file
  --no-ai               Skip AI descriptions
```

## FAQ

### Does ai-env-gen read my actual .env file?

No. It only scans source code for variable references. Your secrets are never accessed or exposed.

### What if I have variables in multiple frameworks?

ai-env-gen detects patterns from Node.js, Vite, Deno, Next.js, and Laravel. Variables are deduplicated and merged into one file.

### Can I use it in CI/CD?

Yes. Use `npx ai-env-gen --no-ai` for deterministic output without API calls. Compare the output against your deployed environment to catch missing variables.

### How does the AI description work?

If `OPENAI_API_KEY` is set, ai-env-gen sends variable names (not values) to GPT to generate helpful descriptions. Use `--no-ai` to skip this.
